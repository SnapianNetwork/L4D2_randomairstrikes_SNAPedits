This is an edit of ChimiChamo's Airstrike mod. It adds more air strikes and hopefully fixes a crash.

# Installation
Put "L4D2_randomairstrikes_SNAPedits" in addons folder (steamapps\common\Left 4 Dead 2\left4dead2\addons\L4D2_randomairstrikes_SNAPedits)

# Types of airstrikes...

* Normal (jet)

* Meteor

* Car drop

* Homing rocket (or smart rocket)

* Nuke (not really a nuke but a giant blast)

* Napalm

* Barrage (multiple normal strikes)

* Cluster bomb

* Nuke2 (An even bigger blast)

* Supply drop (drops a single item)

* Supply drop 2 (drops multiple items)

You can also select the airstrike behavior.

* 0 = near survivors

* 1 = any nav mesh (unstable - may crash the game)

* 2 = Any infected (including indoors)

Much of this can be changed in the settings (left4dead2/ems/random_airstrikes/settings.cfg)
